# Estructuras de Datos desde los fundamentos

Curso abierto e independiente para comprender, implementar y elegir estructuras de datos. Recorre secuencias, listas, pilas, colas, árboles, índices, prioridad, grafos y aplicaciones mediante **71 recursos**, ejercicios resueltos, seis talleres y dos proyectos de integración.

[Comenzar el curso](modulo01/01-tipos-abstractos/README.md) · [Ver el diagnóstico](docs/prerrequisitos.md) · [Volver a Aprende con Leli](https://lelyliliana.github.io/aprende-con-leli/)

## Qué necesitas

Conocer variables, condiciones, ciclos, funciones y clases básicas de Java. No necesitas haber cursado Estructuras de Datos: el recorrido comienza por sus fundamentos. Si todavía estás aprendiendo a programar, utiliza [Java desde cero](https://github.com/lelyliliana/Curso-Java) y [Algoritmos](https://github.com/lelyliliana/Curso-Algoritmos). No se requiere inscripción, cuenta de pago ni un sistema operativo específico.

Los programas usan Java 21, sin dependencias externas. Los ejecutores y las pruebas utilizan Python 3.12 o superior, sin paquetes adicionales. La [guía de ambiente](docs/ambiente-y-herramientas.md) incluye Windows, Ubuntu y macOS y una alternativa de compilación manual.

## Cómo estudiar

1. Lee objetivo, contrato y razonamiento antes de ejecutar.
2. Calcula el caso paso a paso y predice la salida.
3. Abre Main.java y la implementación que utiliza. Algunos ejemplos contienen su propia estructura; otros importan clases compartidas desde src/curso.
4. Ejecuta desde la carpeta indicada y compara con esperado.txt.
5. Resuelve el ejercicio antes de desplegar la solución. Agrega un caso límite y explica su resultado.
6. Sigue el enlace Siguiente recurso y completa el taller del módulo.

Cada lección incluye anterior, índice y siguiente. No necesitas aprender a explorar carpetas de GitHub para seguir la secuencia. La [lectura de implementaciones](docs/lectura-de-implementaciones.md) ayuda a conectar las asignaciones con las invariantes.

## Contenido y garantías

El curso implementa arreglo dinámico genérico, listas, pilas y colas con arreglos y nodos, deques, BST, AVL, B y B+, tablas hash, montículos, trie, conjuntos disjuntos y algoritmos de grafos. Incluye BFS, DFS, Dijkstra, Kruskal, Floyd–Warshall y orden topológico.

El análisis separa tiempo y memoria, peor caso, costo esperado y amortizado. Las pruebas comparan resultados con oráculos y revisan invariantes. Las clases de biblioteca sirven como herramientas de uso y como referencia de comprobación, con su contrato explícito.
